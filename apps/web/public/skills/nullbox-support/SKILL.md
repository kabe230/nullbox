# Nullbox Support

Nullbox is a hackathon demonstration at https://team-05.fasthacks.cloud/ with English and Japanese interfaces. This skill documents the existing web interface; it does not provide an API credential or permission to act.

## Read the portal

Open the public home page. Use the English or 日本語 buttons to select the user's language. The form requires a subject, message, and priority. Name and email are optional. Never enter sensitive personal information into this demonstration.

## Create a ticket only when authorized

Get the user's issue details and permission to send them. Fill the labeled subject and message fields, choose the appropriate priority, and enter optional contact fields only if authorized. Review the completed form before selecting Submit. Do not create test tickets or repeated submissions merely while exploring the site.

## Preserve the private result

After successful submission, show the user their confirmation and private ticket link. The URL fragment is an access token. Keep it private and do not log it, publish it, index it, or share it with another person. Before retrying a submission after an interruption, check whether it already succeeded to avoid duplicate tickets.

## Respect private areas

The worker inbox at /inbox and customer pages at /t/ are not public documentation. Do not enumerate tickets or access an inbox without the user's authority. This catalog contains no private tickets or customer data. No response time or resolution is guaranteed.
